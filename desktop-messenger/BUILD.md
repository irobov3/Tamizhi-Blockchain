# Building Tamizhi Messenger Desktop

## Prerequisites

| Tool | Version |
|------|---------|
| Node | 20.x or newer |
| Rust | 1.78 or newer (stable) |
| Tauri prerequisites | https://tauri.app/start/prerequisites/ |

Install Rust if you don't have it:

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y --default-toolchain stable --profile minimal
source "$HOME/.cargo/env"
```

## One-time setup

```bash
cd desktop-messenger
npm install
```

## Verifying the project

```bash
# Rust compile check
cd src-tauri && cargo check

# Frontend bundle (writes dist/)
cd .. && npm run build
```

## Dev mode

```bash
npm run tauri dev
```

## Producing release artifacts

### macOS (`.app`, `.dmg`)

```bash
npm run tauri build -- --target universal-apple-darwin
# Outputs:
#   src-tauri/target/universal-apple-darwin/release/bundle/macos/Tamizhi Messenger.app
#   src-tauri/target/universal-apple-darwin/release/bundle/dmg/*.dmg
```

For a signed + notarised build, set:

```bash
export APPLE_SIGNING_IDENTITY="Developer ID Application: Tamizhi Foundation (XXXXXXXXXX)"
export APPLE_ID="releases@tamizhi.ai"
export APPLE_PASSWORD="@keychain:notary"
export APPLE_TEAM_ID="XXXXXXXXXX"
npm run tauri build
```

### Windows (`.msi`, `.exe`)

From a Windows host (or via `cross`):

```bash
npm run tauri build -- --target x86_64-pc-windows-msvc
# Outputs:
#   src-tauri/target/x86_64-pc-windows-msvc/release/bundle/msi/*.msi
#   src-tauri/target/x86_64-pc-windows-msvc/release/bundle/nsis/*.exe
```

For signed builds, point at a `.pfx`:

```powershell
$env:WINDOWS_CERTIFICATE        = "base64-encoded .pfx"
$env:WINDOWS_CERTIFICATE_PASSWORD = "..."
npm run tauri build
```

### Linux (`.deb`, `.rpm`, `.AppImage`)

```bash
sudo apt install libwebkit2gtk-4.1-dev libssl-dev libgtk-3-dev libayatana-appindicator3-dev librsvg2-dev
npm run tauri build -- --target x86_64-unknown-linux-gnu
# Outputs:
#   src-tauri/target/x86_64-unknown-linux-gnu/release/bundle/deb/*.deb
#   src-tauri/target/x86_64-unknown-linux-gnu/release/bundle/rpm/*.rpm
#   src-tauri/target/x86_64-unknown-linux-gnu/release/bundle/appimage/*.AppImage
```

## Replacing placeholder icons

The icons under `src-tauri/icons/` are generated by `scripts/gen-icons.cjs` (a flat
indigo square with a gold disc). To use the real Tamizhi logo, drop a 1024×1024 PNG at
`src-tauri/icons/icon.png` and run:

```bash
npm run tauri -- icon src-tauri/icons/icon.png
```

This regenerates every required size plus the `.icns` and `.ico` containers.
